# Interest Calculator: Stack and Order

A simple and compound interest calculator, built to learn the Java ecosystem.

## Stack

- **Java**: the calculation logic (`backend/` classes)
- **Maven**: build tool (`pom.xml` lists libraries and how to build)
- **Spring Boot**: turns the Java code into a web service (REST API)
- **Controller, service, calculation classes**: the standard layered structure
- **Validation and error handling**: clear errors instead of bad numbers
- **JUnit 5**: automated tests built from the slide examples
- **HTML, CSS and JavaScript**: phone-friendly page served by the same app
- **Docker and a free host**: a link that works on a phone without the laptop

## Order

1. Convert the project to the Maven layout
2. First Spring Boot app that starts and answers a request
3. Service and controller that wrap the calculation classes
4. Validation and error messages
5. JUnit tests
6. Phone-friendly front end
7. Docker and deployment
